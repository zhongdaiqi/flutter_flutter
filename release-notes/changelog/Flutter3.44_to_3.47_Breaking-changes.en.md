# Changelog: Flutter 3.44 to Flutter 3.47

The version differences from Flutter 3.44 to Flutter 3.47 mainly cover the OpenGL ES render-to-texture storage behavior, the semantics header and headingLevel behavior on iOS and Android, and a foundation library API removal. Developers need to pay attention to the changes that require adaptation.

## Detailed Changes from Flutter 3.44 to Flutter 3.47 are as follows:

| No | Title | Source Version of Change | Is Adaptation Required? | Change Guidance |
| :-: | --- | :----------------------: | :---------------------: | --- |
| 1 | OpenGL ES render-to-texture content is stored top-down | 3.47 | No | [https://docs.flutter.dev/release/breaking-changes/opengles-render-to-texture-top-down](https://docs.flutter.dev/release/breaking-changes/opengles-render-to-texture-top-down) |
| 2 | Update semantics header and headingLevel behavior on iOS and Android | 3.47 | No | [https://docs.flutter.dev/release/breaking-changes/semantics-header-heading-level](https://docs.flutter.dev/release/breaking-changes/semantics-header-heading-level) |
| 3 | Removal of describeEnum | 3.47 | No | [https://docs.flutter.dev/release/breaking-changes/remove-describeEnum](https://docs.flutter.dev/release/breaking-changes/remove-describeEnum) |
