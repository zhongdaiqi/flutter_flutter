## Version Overview
This version is an OpenHarmony version based on Flutter 3.22.0. This version supports and improves the capabilities of the OpenHarmony platform and improves stability.

## Release Scope
OpenHarmony API 15

## New Features
- Added OpenHarmony webview_cookie_manager library

## Version Release Time
April 1, 2025

## Version Support
- Minimum Engine Build API: **OpenHarmony API 15**
- Target App Build API: **OpenHarmony API 15**
- Minimum App Runtime API: **OpenHarmony API 12**
- Flutter SDK: **3.22.0-ohos-0.1.1**
